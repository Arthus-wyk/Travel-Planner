# 地点定位与地图审核页实施计划

目标：地点选择支持 POI 确认、坐标与静态地图；独立审核页按天展示地图与可拖动行程，右侧保留跨天中转的未确定行程。

实现：复用高德适配器与现有 planning JSON；MySQL 增加按接口与请求参数散列的缓存表，地点/地图缓存30天、路线缓存24小时。图片只保存在缓存表，通过同源图片接口读取，计划 JSON 不包含图片。审核页顶部地图，下面 7:3 分栏，左侧日导航与行程，右侧未确定行程。固定交通和家/酒店锚点保持固定，可移动景点；提供按钮作为拖动的键盘替代。

- [x] 数据库缓存、路线折线、带路线静态地图、POI 查询与确认 API。
- [x] 未确定行程、逐段交通方式、实际耗时排时、地图读取与审核。
- [x] 独立前端路由、POI 选择、地图与 7:3 拖动交互。
- [x] 缓存/排时/跨天操作/API 测试和前端构建。

检查：67 项相关测试通过，Vite 构建通过；浏览器使用模拟数据验证日期切换、卡片拖到暂存栏与跨天加入。独立审查发现并修复 POI 更名后刷新推荐丢失用户元数据，新增回归。进出站接驳支持填写实际出发/到达站，并参与交通方式选择与排时；未确认具体站点的接驳仍明确标注估算。

未做真实 MySQL 和高德 API 联调。静态地图图片不是实景照片，交通预算仍沿用每日额度。
