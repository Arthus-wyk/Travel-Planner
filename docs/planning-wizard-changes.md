# 规划向导修改记录

## 2026-11-14

- 将「选活动与攻略」作为页面视图记录在 URL 中。已有审核路线时，进入此视图不会写入规划阶段。返回审核时，未保存的攻略文字或附件仍受离开确认保护。

- 通过 `frontend/tests/guideUpload.browser.mjs` 覆盖导航、草稿保护、延迟提交和生成进度。旧版已保存为活动阶段的行程仍需重新生成，现有数据没有记录其回退前的阶段或回退后的修改。
